# 📚 Riglify Wiki

The Riglify Wiki contains documentation, guides, technical information, troubleshooting solutions, and development resources for the project.

## 🚀 Visit the Wiki

👉 **[Open the Riglify Wiki](../../wiki)**

## 📖 What's Inside?

### 🏁 Getting Started
Learn how to use Riglify, import Roblox avatars, download assets, and export models.

### 👤 Avatar Importing
Learn how Riglify retrieves Roblox avatars, currently-worn assets, body parts, accessories, clothing, and other avatar information.

### 📦 Asset Downloads
Information about downloading individual Roblox assets and how Riglify handles supported and unsupported asset types.

### 🗂️ Supported Export Formats
Learn about Riglify's supported and planned formats, including:

- `.RBXM`
- `.OBJ`
- `.GLB`
- `.FBX`
- `.PLY`
- `.STL`
- `.DAE`
- `.MESH`

### 🛠️ Troubleshooting
Solutions to known problems, errors, compatibility issues, missing textures, broken exports, and other Riglify problems.

### 💻 Developer Documentation
Technical information for developers who want to understand, modify, or contribute to Riglify.
